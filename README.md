A simple console-based notes management bot built with Python using OOP principles.
Features:
-create notes
-delete notes
-view all notes
-simple command-based interaction
-structured with class inheritance

Architecture:

The project is built using a chain of classes:

- "Task" - represents a single task(note)
- "TaskManager" - manages a collection of tasks (add, delete, view full list)
- "Bot" - handles user interaction and commands
